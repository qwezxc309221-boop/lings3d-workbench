# 中文工作台使用指南

## 启动和停止

```bash
./workbench/start.sh
./workbench/stop.sh
```

页面地址为 <http://localhost:8080>。控制服务、采集桥接、三维视口分别使用本机 8080、8092、8091 端口。分享包不安装桌面快捷方式。

如原服务已在运行，启动脚本会复用该服务；要切换到当前项目目录，应先保存正在进行的拍摄并停止原服务。不要在录制或重建中切换。

## 采集

1. 相机通电，接好有线网络，确认主机有 `192.168.0.x` 地址。
2. 打开页面，点击“连接相机”，等待左右图像和标定状态就绪。
3. 点击“＋新建”，输入扫描名称，然后“开始拍摄”。缓慢移动，保持画面重叠。
4. 需要停顿时点击“暂停拍摄”。继续会产生新拍摄段，独立段不会自动拼接。
5. 点击“结束并保存”，等待已入队帧写入完成。

默认每秒保存 3 对校正图；接收帧率不等于保存帧率。每 300 对自动切换文件子目录，仍属于同一段，不重置轨迹。写入队列有界，磁盘不足、断流或写入过载会暂停并提示。

## 重建和浏览

1. 选择已保存的扫描和拍摄段。
2. 选择“双目视差 + LingBot 融合”或“原单目 LingBot（对比）”。
3. 点击“开始重建”，观察加载、推理、融合及保存进度。同一时间运行一个 GPU 任务；推理时不启动新的拍摄。
4. 完成后自动打开结果。已有结果可以直接“打开结果”，无需重算。
5. 在三维视口切换“全部帧/当前帧”、回放、点大小、置信度及显示降采样。

双目支持区域包含双目优先点和双目/神经一致混合点；神经补全没有直接视差测距支持。来源着色中绿色表示双目支持、橙色表示神经补全。置信度滑块采用分位数过滤，数值不是准确率。

## 导出

先在三维视口点击“导出当前过滤点云 PLY / GLB”，再在外侧下载。导出反映当前帧、来源、置信度和降采样设置；显示居中/缩放不改变导出坐标。当前 GLB 为点云。

完整几何通过几何下载入口获取。新结果为含索引及 NPZ 块的 ZIP；旧结果可为单个 `geometry.npz`。深度对比图展示不同来源的深度，不是误差真值图；融合报告记录尺度、覆盖率及位姿来源。

## 数据组织

默认扫描路径为 `$LINGS_ROS_ROOT/scans/<scan_id>/`。

| 路径 | 内容 |
|---|---|
| `scan.json` | 扫描及段信息 |
| `segments/<segment>/left/`、`right/` | 同步校正 PNG |
| `frames.jsonl` | 已提交帧与左右纳秒时间戳 |
| `calibration.json` | K、D、R、P、尺寸与坐标标识 |
| `result/` | 单目结果 |
| `result_stereo/` | 双目融合结果 |
| `geometry/index.json`、`geometry/*.npz` | 完整分块深度、内参、W2C 位姿等 |
| `cloud.npz` | 有点数预算的显示概览 |
| `result.json`、`progress.json` | 结果及任务进度 |

## 删除和中断恢复

“移至回收站”移动工作台扫描，可恢复，不删除 RTAB-Map 数据库。拍摄任务先保存，推理任务先取消。断开相机停止工作台桥接，不等于关闭硬件电源。

服务重启后按提交日志恢复已写帧，未完成写入的帧不能恢复。取消或失败的重建从原图重放，尚无 Transformer 会话中途检查点恢复。

## 精度和适用边界

网络仍处理左目多帧；外部几何分支用同步右目和标定计算视差、尺度及 PnP 运动。410×308、约 6.96 cm 基线对远景、细节、弱纹理及反光区域有限制。神经补全不能代替直接测量，PnP 通过不等于轨迹准确。

先按已知尺寸物体和返回起点的移动序列验证，再判断测量精度。实际水下使用还需验证标定介质和外壳折射适用性。

代码检查及自动测试见[验证记录](validation.md)。
