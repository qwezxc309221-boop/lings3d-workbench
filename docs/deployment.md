# 部署配置

## 主机与容器

推理在主机 Python 环境运行；ROS Melodic 使用容器的 Python 2。两者通过宿主挂载目录中的图像、标定和清单交接。不要把主机推理依赖安装进 ROS 容器。

`docker/run.sh` 使用主机网络、X11 及现有 NVIDIA 驱动库挂载，适用于原项目的 Linux 图形环境。Wayland、无桌面服务器、其他 GPU 及驱动布局需要单独适配。脚本需要 `docker`、`xhost`，相机侧需能访问局域网。

## 路径

默认挂载为：

```text
宿主：<项目>/docker/catkin_ws/src
容器：/root/catkin_ws/src
```

工作台读取 `LINGS_ROS_ROOT/scans`，容器桥接写入 `/root/catkin_ws/src/lings_3d/scans`。两者必须落在同一份数据目录。已有容器不因解压新代码而自动切换挂载。

## 设备配置

原设备 IP 为 `192.168.0.12`，话题位于 `/sensor_stereo_2`。相机地址在 `workbench/server.py`，订阅话题在 `workbench/ros_bridge.py` 和 ROS launch 中。更换相机时同时检查图像编码、CameraInfo、左右顺序和精确同步条件。

当前双目融合只支持水平校正双目及已支持的畸变模型。标定由设备读取并随拍摄段保存，不能把原设备基线当作其他相机参数。

## 端口

| 服务 | 地址 |
|---|---|
| 工作台 | `127.0.0.1:8080` |
| 三维视口 | `127.0.0.1:8091` |
| 采集桥接 | `127.0.0.1:8092` |

服务面向本机使用。只运行一个控制服务，推理任务由同一后端管理。

## 数据与精度

数据、缓存和权重不随源码分发。换机器前分别备份扫描、RTAB-Map 数据库及导出模型。固定设备应先用已知尺寸物体验证尺度，再做慢速移动和返回起点测试。水下介质、外壳、焦距或分辨率变化后需重新检查标定适用性。
